q: What does **HTTP** stand for?
a: HyperText Transfer Protocol — a *stateless* application-layer protocol.

q: OSI layers, top to bottom
a:
1. Application
2. Presentation
3. Session
4. **Transport** (TCP/UDP)
5. Network
6. Data Link
7. Physical

q: The TCP handshake is ==SYN== then ==SYN-ACK== then ==ACK==.
e: The three-way handshake establishes a connection before any data flows.

q: Type the HTTP status code for "OK"
t: 200
